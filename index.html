Comment automatiser, sécuriser et superviser un parc de commutateurs industriels Cisco ? Voici les coulisses techniques de mon projet.

Le Défi Technique

En milieu industriel, de nombreux équipements (automates, capteurs) ne communiquent pas via les protocoles de découverte classiques comme Cisco CDP et n'apparaissent pas toujours dans la table de routage IP s'ils communiquent en local.

La solution : Développer un outil en Python qui interroge directement la couche physique (Table MAC) du commutateur, puis qui croise ces données avec la table ARP pour identifier 100% des équipements branchés sur les ports avec leurs noms et leurs adresses.

Extrait du Code Python (trouver le nom des voisins)

Note de sécurité : L'extrait de code ci-dessous a été volontairement tronqué et anonymisé (masquage des expressions régulières IP complètes et des noms de variables internes) afin de respecter la politique de cybersécurité de l'entreprise. 
# 1. Récupération de la table des adresses MAC (Couche 2)
mac_output = net_connect.send_command("show mac address-table")
mac_entries = []

for line in mac_output.splitlines():
    # Capture Regex : VLAN | MAC | Type | Port
    match_mac = re.search(r"(\d+|All)\s+([0-9a-fA-F\.]{14})\s+\S+\s+(\S+)", line)
    
    # On isole les ports physiques (exclusion du CPU)
    if match_mac and match_mac.group(3).lower() != "cpu":
        mac_entries.append({
            'mac': match_mac.group(2),
            'port': match_mac.group(3)
        })

# 2. Corrélation avec la table ARP (Couche 3)
arp_output = net_connect.send_command("show arp")
arp_dict = {}

for line in arp_output.splitlines():
    # Anonymisation du pattern IP local
    match_arp = re.search(r"Internet\s+(10\.\d{1,3}\.X\.X)\s+.*?\s+([0-9a-fA-F\.]{14})", line)
    if match_arp:
        arp_dict[match_arp.group(2)] = match_arp.group(1) # Association {MAC: IP}

Outil d'Injection Automatique (Liaison Série)

Afin de simplifier le déploiement des commutateurs industriels IE-2000 fraîchement sortis d'usine, ce script automatise la détection matérielle et l'envoi des fichiers de configuration.

La valeur ajoutée : Plus besoin de chercher manuellement le numéro de port COM dans le Gestionnaire de périphériques Windows. Le script scanne les descriptions matérielles, identifie le câble console Cisco et pousse l'intégralité de la configuration d'usine via Netmiko.

Note de sécurité : Les chemins réseau d'accès aux configurations ont été anonymisés. 
# 1. Détection automatique du câble console branché sur le PC
ports = list(serial.tools.list_ports.comports())
port_console = None

for port in ports:
    if "USB" in port.description or "Serial" in port.description or "Cisco" in port.description:
        port_console = port.device
        break

# 2. Connexion et injection de la configuration d'usine
switch_console = {

Simulateur de Pannes Réseau (Lab Cybersécurité)

Développé pour la plateforme de formation interne, cet outil permet d'injecter des anomalies réseau contrôlées sur un poste de travail Windows pour tester la résilience des applications industrielles.

La valeur ajoutée : Ce script Python fait office de passerelle en pilotant l'API PowerShell de Windows (via `subprocess`) pour manipuler les tables de routage, le pare-feu local ou l'état des interfaces réseau sans intervention manuelle. 

# Création d'un trou noir (Blackhole) pour couper une route spécifique
def route_add_blackhole(iface, dest_cidr, nexthop="192.0.2.1"):
    # 192.0.2.0/24 correspond à TEST-NET-1 (non routable), idéal pour absorber le trafic
    ps(rf'New-NetRoute -InterfaceAlias "{iface}" -DestinationPrefix "{dest_cidr}" -NextHop "{nexthop}"')

# Simulation d'une micro-coupure physique (Interface Flapping)
def flap_iface(iface, down_s, up_s, cycles):
    for i in range(cycles):
        print(f"--- Flap {i+1}/{cycles}: DOWN {down_s}s / UP {up_s}s")
        ps(rf'Disable-NetAdapter -Name "{iface}" -Confirm:$false')
        time.sleep(down_s)
        ps(rf'Enable-NetAdapter -Name "{iface}" -Confirm:$false')
        time.sleep(up_s)
